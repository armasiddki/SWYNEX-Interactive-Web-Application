# Book Reading Tracker
  A simple and responsive React-based web application for managing and tracking books.

## Features
 - Add new books
 - Edit existing books
 - Delete books
 - Search books by their title or author name
 - Filter books by reading status
 - Dynamic reading statistics
 - Form validation
 - Local storage for saving books
 - Reusable React components
 - Responsive design for different screen sizes

### Technologies Used
 - React
 - JavaScript
 - HTML
 - CSS 
 - Vite
 - Local Storage

#### Project Purpose
 This project was created as part of my Frontend Development Intership at SWYNEX Technologies.
 This project focuses on practising React state management, reusable components, form handling,
 validation, responsive UI development, and browser-based data storage.
